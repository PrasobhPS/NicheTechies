About the Role

At Niche Techies, we partner with industry-leading enterprises and high-growth venture-backed startups across North America, Europe, and Asia to engineer resilient, high-throughput digital products.

As a Full Stack Developer on our core engineering team, you will design, build, and maintain mission-critical web applications from the ground up. You will own features across the complete development lifecycle — from participating in architectural design reviews and authoring clean TypeScript APIs to building fluid React user interfaces and optimizing cloud deployment pipelines.

What You'll Do

  • Full-Stack Architecture: Architect and implement scalable web applications using React, TypeScript, Node.js, and modern relational/NoSQL data stores.
  • API & Microservices: Design secure, performant RESTful endpoints and GraphQL schemas, adhering to clean architecture and domain-driven design principles.
  • Performance Optimization: Optimize Core Web Vitals, frontend asset bundling, query latency, and database indexing to deliver sub-second response times.
  • Automated Testing & Quality: Author robust unit, integration, and end-to-end tests (Jest, Playwright, React Testing Library) to maintain 90%+ test coverage.
  • Cloud & DevOps: Collaborate with our platform engineers to deploy containerized microservices to AWS/GCP using Docker and automated CI/CD pipelines.
  • AI-Assisted Innovation: Experiment with and integrate generative AI developer tools and autonomous LLM agentic patterns into internal workflows and client applications.

What We're Looking For

  • 3 to 6 years of professional software development experience building production-grade web applications.
  • Deep expertise in React, Next.js, TypeScript, and modern state management (Redux Toolkit, Zustand, or TanStack Query).
  • Strong backend fundamentals in Node.js (Express, Nest.js, or Fastify), asynchronous event loops, and microservices patterns.
  • Proven track record with relational databases (PostgreSQL, MySQL) and familiarity with ORMs (Prisma, TypeORM, Drizzle).
  • Working knowledge of Docker containerization, git flow, and automated CI/CD pipelines (GitHub Actions, GitLab CI).
  • Excellent communication skills with the ability to explain complex technical trade-offs to product stakeholders and cross-functional teams.

Nice to Have

  • Hands-on experience deploying services on AWS (ECS, Lambda, S3, RDS, CloudFront) or GCP.
  • Familiarity with event-driven architectures using Kafka, RabbitMQ, or AWS SQS.
  • Experience with Python, LangChain, or LLM-powered development workflows.
  • Active contributions to open-source software, personal tech projects, or technical blogs.
